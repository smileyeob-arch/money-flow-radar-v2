# 3개월 과거 상승 테마 추정 복원 — 최초 1회 실행

## 무엇이 복원되는가

2026년 11월 6일 기준 **2026-08-06부터 2026-11-06까지** 과거 주식 일봉의 **실제 종가와 거래대금**을 조회합니다.

**인포스탁의 과거 일별 공식 테마 상승률 및 과거 테마 편입종목 이력은 제공받지 못했습니다.**
따라서 현재 인포스탁 테마 구성으로, 과거 거래일별 **거래대금 500억원 이상이었던** 코스피·코스닥 일반주를 분류하고 당시 평균 등락률로 날짜별 **테마 1·2위 추정 순위**를 만듭니다. 공식 인포스탁 과거 순위와 동일하다고 주장하지 않습니다.

- 과거 3개월 상승일: 당시 시세를 실제 일봉에서 재생. 현재도 상장된 일반주만 포함(과거 상장폐지 종목 제외)
- 500억원 조건: 오늘이 아니라 **각 과거 거래일 거래대금** 기준
- 관심종목: 추정 1·2위 테마에서 당시 상승한 종목 중 거래대금 상위 2개
- 현재 관심 상태: 최초 선정일 이전 최대 20거래일 저점 / 이후 고점 / 20일 이동평균 / Fib 0.236, 0.382, 0.5, 0.618
- 오늘 거래대금이 500억원 미만인 종목도 과거 선별 조건을 충족했다면 추적
- 이미 기록된 당일 테마 기록은 보존, 과거 재구성은 화면에서 '과거 추정'으로 표시
- 자동 매수·매도 없음

## 직장/집 PC 실행 방법

키움 REST API가 해당 PC의 공인 IP로 인증되는 환경에서, 기존에 키를 암호화 저장해 둔 Windows 사용자로 실행하세요.

PowerShell 위치: C:\Users\사용자\money-flow-radar-v2

1. 먼저 최신 코드 가져오기:

    git pull origin main

2. 최초 1회 과거 복원 실행:

    powershell -NoProfile -ExecutionPolicy Bypass -File .\windows\backfill-3months.ps1

2,000개 이상 일반주의 과거 일봉을 조회하므로 PC 전원과 인터넷 연결을 유지하세요. 도중 중단되면 %LOCALAPPDATA%\MoneyFlowRadar\historical-cache 에 중간 결과를 보관합니다. 같은 명령을 다시 실행하면 조회한 차트를 재사용합니다. 호출 제한을 지키기 위해 API를 순차 요청합니다.

성공 로그 예시(숫자는 실제 조회 결과에 따라 달라짐):

    BACKFILL SUCCESS: ... trading sessions; ... historical top-2 events added; ... currently tracked shares
    BACKFILL PUBLISHED: radar-history.json; Pages deployment triggered.

복원이 성공하면 https://smileyeob-arch.github.io/money-flow-radar-v2/ 의 '◎ 3개월 눌림목 추적'에서 '3개월 전부터' 또는 '과거 추정 복원만' 정렬 선택.

## 이후 매일 운영

기존 windows/run-and-publish.ps1 을 계속 사용합니다. 이 백필은 **최초 1회 실행용**이므로 매일 수천 건의 API 호출을 반복하지 않습니다.

## 안전 및 한계

- 기존 data/latest.json 거래대금 데이터는 변경하지 않으며, 성공 시 data/radar-history.json 만 업데이트합니다.
- API 오류나 과거 자료 부족 시 데이터 업로드를 중단합니다. 기존 GitHub 데이터는 유지됩니다.
- 계좌·인증키·토큰을 GitHub 저장소에 넣지 않습니다.
- 테마 구성은 **현재 편입종목** 기준이므로 과거와 다른 테마/상장폐지로 인한 생존편향을 포함합니다.
- 과거 공식 테마 1·2위가 아니라 추정 순위로, 매수 시점 판단의 보조 자료입니다.
