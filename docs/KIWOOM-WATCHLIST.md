# 내 키움 관심종목 불러오기 (로컬 보안 방식)

## 지원 기능

키움 영웅문에 저장된 관심종목 그룹을 키움 REST API로 읽기 전용 조회:
- ka01300: 관심종목 그룹 목록 (nofi, gcod, name)
- ka01301: 해당 그룹 종목 목록 (요청 arn_grp_id, 응답 nofj, cod2)
- ka10099: 코스피/코스닥 일반주 확인
- ka10081: 종목 일봉, 20일 이동평균선 및 피보나치 가격 계산

계좌 잔고, 보유수량, 수익률, 계좌번호, 주문 내역은 조회하지 않습니다. 주문도 하지 않습니다.

## 개인정보 보호

공개 GitHub Pages 웹사이트에 키움 인증키나 개인 관심종목을 직접 저장하면 위험하므로, 개인 관심그룹은 Windows의 LOCALAPPDATA 폴더에만 내보냅니다. 웹앱은 선택한 JSON 파일을 **브라우저 안에서만** 읽습니다. 파일을 GitHub에 업로드하거나 공개 저장소에 커밋하지 않습니다. 다른 기기와 자동 동기화되지 않으며 브라우저 새로고침 이후 다시 파일을 불러와야 합니다.

## PC에서 1회 실행

이미 API 인증이 완료된 직장 노트북 또는 집 PC에서 money-flow-radar-v2 폴더의 PowerShell 창을 열고:

    powershell -NoProfile -ExecutionPolicy Bypass -File .\windows\export-watchlist.ps1

정상적으로 연결되면 콘솔에 그룹별 종목 수와 "EXPORT SUCCESS"가 표시되고 아래 파일이 생성됩니다.

    %LOCALAPPDATA%\MoneyFlowRadar\watchlist-export.json

## 웹앱 사용

1. https://smileyeob-arch.github.io/money-flow-radar-v2/ 접속
2. "3개월 눌림목 추적" 선택
3. "종목 출처" -> "내 키움 관심종목 (로컬 파일)"
4. "관심종목 파일 선택" 클릭
5. 파일 선택창에서 %LOCALAPPDATA%\MoneyFlowRadar\watchlist-export.json 입력
6. 그룹을 선택하고 원하는 종목을 클릭하면 오른쪽에 20일선 및 피보나치 0.236/0.382/0.5/0.618, 가격 차트를 표시

개인 관심종목은 과거 테마 1~2위 종목이 아니므로, 프로그램은 공식 상승 테마 선정일을 꾸며내지 않고 과거 90거래일 내의 가격 변동에서 저점과 그 이후 고점을 찾아 기술적 되돌림을 표시합니다.

기존 거래대금 500억원 컷은 주도주 발굴용이고, **개인 관심종목에는 적용하지 않습니다.** 코스피/코스닥 일반주 대상은 유지됩니다.

관심그룹을 영웅문에서 수정했다면 로컬 내보내기를 다시 실행하고 새 파일을 선택하세요.

## 제한 및 주의

- API의 실제 개인 그룹 응답은 아직 사용자 PC에서 검증되지 않았으므로 초기 테스트가 필요합니다.
- 개인 JSON 파일은 그룹 이름·종목코드·시장 시세를 담습니다. 투자 관심사가 드러나므로 공개 업로드하지 마세요.
- PC나 인터넷 장애 시 개인 관심종목 수집이 실패할 수 있습니다. 기존 공개 웹앱 자료는 영향을 받지 않습니다.
