## 중요한 데이터 갱신

**실제 일봉을 만들어내지 않습니다.** 11월 6일 이전에 내보낸 개인 JSON은 시가·거래량이 없고 1년 전체 봉도 부족할 수 있습니다. 새 차트는 이 경우 캔들을 그리지 않고 재수집 안내를 보여줍니다.

키움 API가 등록된 PC의 기존 폴더에서 아래 명령으로 내 키움 관심종목 파일을 **다시 수집한 후** 웹앱에 새 JSON을 선택하세요.

    powershell -NoProfile -ExecutionPolicy Bypass -File .\windows\export-watchlist.ps1

이번 버전은 260거래일까지 저장하고 로컬 캐시 파일 버전을 v3으로 분리합니다. 예전 차트 캐시를 재사용하지 않으며 대량 관심종목은 25개마다 로컬 저장 후 중단 시 재시작이 가능합니다.

공개 '3개월 주도 테마' 차트도 키움 등록 PC에서 **장마감 이후** 기존 명령을 실행해야 시가·거래량을 새로 수집합니다.

    powershell -NoProfile -ExecutionPolicy Bypass -File .\windows\run-and-publish.ps1

개인 관심그룹·인증키·계좌는 GitHub로 업로드하지 않습니다.

외부 라이브러리 로드가 막히면 기존 내부 SVG 캔들 렌더러로 대체하되, 실제 OHLC가 없으면 무조건 재수집 안내를 보여줍니다.

사용 라이브러리: TradingView Lightweight Charts 5.0.9, https://tradingview.github.io/lightweight-charts/ , Apache-2.0.
