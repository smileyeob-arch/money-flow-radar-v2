# v3 — 3개월 주도 테마 / 20일선 / 피보나치 눌림목 감시

## 어떤 문제를 해결하는가
장마감 종목 거래대금 상위 화면만으로는 며칠 전에 상승했던 종목이 거래대금 500억원 미만으로 떨어진 뒤 추적되지 않습니다.
이 도구는 **처음 상승했던 날을 별도로 기록**하고, 이후 92일간 선정 종목의 일봉을 다시 조회해 눌림을 관찰합니다.

- 자동 주문 **없음**. 매매는 사용자가 직접.
- 원천 데이터는 집/직장 IP 등록된 PC에서 키움 REST API로 수집.
- 인포스탁 API `ka10106/ka10107`은 **현재 테마 편입 정보만** 제공합니다.
- **인포스탁 과거 일별 공식 테마 상승률 1·2위를 제공하는 원천 데이터는 아직 연결되지 않았습니다.**
  지금의 1·2위는 그날 거래대금 500억원 이상 일반주 중 테마별 평균 등락률 대용 순위입니다.
  테마에 포함된 감시종목이 2개 이상, 평균 상승률 양수, 상승 종목이 50% 이상인 테마만 후보가 됩니다.
- 1·2위 테마마다 **상승 종목 중 거래대금 상위 2개**를 자동 관심종목으로 기록합니다.
- 같은 종목이 여러 테마/날에 선정되어도 한 종목으로 추적하며 날짜별 상승 이력을 보존합니다.

## 추적 계산
- 매일 장 마감 이후 **15:40 KST부터** 새 테마 1·2위 선정 기록을 만들 수 있습니다.
  15:40 이전 수집은 잠정 수치일 수 있으므로 새 기록을 만들지 않습니다.
- 수집 날짜별로 `data/radar-history.json`에 현재 가격, 최초 상승일, 테마 순위, 대상 종목의 일봉을 보존합니다.
- 과거 3개월의 순위가 없으면 **과거를 소급 생성하지 않습니다**.
  프로젝트에서 저장을 시작한 날 이후 날짜별로 누적하고 오래된 기록은 92일 후 제외합니다.
- 관심종목은 이후 거래대금 500억원 미만이어도 92일간 계속 종가를 조회합니다.

### 20일선
`MA20 = 최근 20거래일 종가 합계 / 20`.
현재 종가와 MA20의 이격도가 ±3% 이내이면 관심 구간 후보입니다.

### 피보나치 기준
- **기준 저점 L:** 첫 관심일 이전 최대 20거래일의 최저가
- **상승 고점 H:** 첫 관심일 이후 현재까지 최고가
- 되돌림 가격 = `H - (H - L) * r`
- r = 0.236 / 0.382 / 0.500 / 0.618
- 0.382 수준 ±3%를 우선 관심으로 봅니다.
- 정상적인 상승과 눌림을 구분하기 위해 상승폭 8% 이상, 고점 대비 15% 이상 되돌림, 최초 기록 후 최소 4개 거래일 조건을 적용합니다.
- 20일선과 피보 0.382가 동시에 근접하면 **20일선·피보 중첩**, 하나만 가까우면 해당 관심 상태.
- 종가가 피보 0.618보다 2% 이상 낮고 20일선 아래라면 **이탈 주의**.
- 위 범위는 실험적인 스크리닝 기준이며 수익성 검증이나 매수 신호가 아닙니다.

## 배포 / 재수집
1. IP가 키움에 등록된 PC에서 기존 PowerShell 경로로 이동.
2. `powershell -NoProfile -ExecutionPolicy Bypass -File .\windows\run-and-publish.ps1` 실행.
3. 로그 `3-month tracker: ...` 및 `SUCCESS: ... pushed` 확인.
4. 자동 GitHub Pages 배포 후 **3개월 눌림목 추적** 탭에서 조회.
5. 이전 `data/latest.json`은 그대로 유지하면서 새 `data/radar-history.json`이 추가됩니다.

- 화면의 수급/눌림 상태는 과거 데이터로 계산한 참고 신호일 뿐 보장된 매수 시점이 아닙니다.
