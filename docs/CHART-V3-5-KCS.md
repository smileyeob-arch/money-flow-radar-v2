# v3.5 — K차트스캐너 스타일 차트

**적용 화면:** Money Flow Radar → 3개월 눌림목 추적 → 주도 테마 또는 내 키움 관심종목 → 종목 클릭

사용자가 제공한 **K차트스캐너 실제 디자인 시안**의 차트 스타일을 기준으로 동일한 시각 구성을 웹 환경에서 재구현했습니다. K차트스캐너 앱의 원본 프런트엔드 코드를 복사한 것은 아닙니다.

- 어두운 남색 격자 배경, 캔들(상승 빨강 / 하락 파랑)
- 이동평균선 **5일 흰색 / 10일 파랑 / 20일 노랑 / 60일 초록 / 120일 보라**
- 차트 하단 **거래량 막대**
- 피보나치 **0.236~0.382 하단 구간에만 반투명 민트색 채움과 경계선** 표시
- 피보나치 숫자는 차트에 적지 않으며, 기존 **종목 분석 수치 카드**에서 확인
- RSI · MACD는 계산/화면에서 제거
- 1개월/3개월/6개월/전체(입력된 일봉 기준) 범위 버튼, 마우스 크로스헤어와 시·고·저·종/거래량·10/20 이평가 조회
- 코드 경로: `radar-chart.js`, `radar-chart.css`; 대시보드 연동 `radar-ui.js`; 로컬 차트 `scripts/export_kiwoom_watchlist.py`
- **가짜 캔들 금지:** 기존 로컬 JSON에 시가/거래량이 없으면 종가 선그래프/거래량 없음으로 안전하게 폴백. 실제 캔들을 원하면 `windows/export-watchlist.ps1`을 실행해 새 `watchlist-export.json`을 불러와야 함
- 주도 테마 캔들 데이터는 로컬 PC의 기존 `windows/run-and-publish.ps1`으로 장마감 재수집해야 함
- 키움 HTS 관심그룹, 파일 내 개별 삭제, 3개월 과거 테마 분석, 기존 거래대금 웹앱 데이터는 유지
- 투자판단용 보조 시각화로 자동 매수/매도 없음

시안 속 "급등/매수 신호" 텍스트 화살표 등 **예시 전략 주석은 임의 생성하지 않음**. 실제 조건 판단과 시계열 검증이 있을 때만 추후 별도 추가.
