# Money Flow Radar v3.4 — HTS 스타일 기술적 차트

## 디자인과 구성
'3개월 눌림목 추적'에서 주도 테마 종목 또는 내 키움 관심종목을 클릭하면 오른쪽에 진한 남색 금융 차트가 나타납니다.

- **빨강 = 당일 종가가 시가보다 높음**, **파랑 = 당일 종가가 시가보다 낮음** (일봉 캔들)
- MA 10(노랑), 20(주황), 60(파랑), 120(보라); 충분한 기간이 없는 이평선은 —로 표시
- 피보나치 되돌림 0.236, 0.382, 0.5, 0.618 가격 선; 기존 프로젝트의 저점/고점 선정방식 유지
- 일별 실제 거래량(주식 수), RSI(14, Wilder), MACD(12,26,9)
- 차트 기간: 1개월(최대 22거래일), 3개월(66), 6개월(132), 전체(수집된 최장 약 200거래일)
- 마우스 커서: 날짜, 시가·고가·저가·종가, 거래량, RSI 값
- 기존 영웅문 관심그룹 선택/종목 클릭/개별 삭제 및 주도 테마 3개월 복원 모두 유지

## 데이터의 출처와 구버전 처리
키움 REST ka10081의 `open_pric`, `high_pric`, `low_pric`, `cur_prc`, `trde_qty`를 실거래일별 OHLCV로 수집합니다.

**이전(3.3 이하) 로컬 `watchlist-export.json`에는 시가와 거래량이 없으므로, 캔들 대신 종가선이 나타나고 거래량 없음이 표시됩니다.** 기존 시가를 전일 종가나 현재 종가로 채워 **가짜 캔들**을 만들지 않습니다.

완전한 캔들과 거래량 차트를 보려면 등록된 키움 PC에서 최신 `scripts/export_kiwoom_watchlist.py`를 사용하여 아래 명령을 재실행하세요.

```powershell
powershell -NoProfile -ExecutionPolicy Bypass -File .\windows\export-watchlist.ps1
```

이 명령은 최신 GitHub 코드로 업데이트한 뒤 개인 로컬 폴더에 재수집합니다. 이번 버전은 `watchlist-chart-cache`의 형식을 v2로 분리했기 때문에 1,545개 관심종목을 새로 조회할 수 있습니다. 그룹 목록과 계좌/암호는 GitHub로 전송하지 않습니다.

**주도 테마 추적 데이터**도 새로운 캔들형 차트를 보려면 키움에 등록된 PC에서 기존 `windows/run-and-publish.ps1` 장마감 수집을 한 번 실행해 `data/radar-history.json`의 OHLCV가 갱신되도록 해야 합니다. 개인 관심종목 로컬 JSON과 공개 3개월 테마 복원 기록은 별도입니다.

## 주의
- 웹앱은 장마감 기준 정적 차트이며 실시간 체결·자동 주문 기능은 없습니다.
- 데이터가 없는 이동평균 또는 거래량은 빈 값으로 표시하고 임의 가격을 생성하지 않습니다.
- MA120은 수집 가능한 거래일이 120개 이상일 때만 보입니다.
- 기술적 지표와 피보나치 가격은 매매 보조 정보일 뿐 투자 성과를 보증하지 않습니다.
